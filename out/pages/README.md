# DSPy demo

A self-contained tech-share deck on the DSPy framework (v3.5), built from a real
benchmark-selection experiment.

- `index.html` — the interactive deck (arrow keys or the numbered buttons to navigate;
  click the concept cards on page 1 for detail)
- `no-js.html` — the same content with no JavaScript, using native `<details>` elements

Both files are single-file and offline: no network calls, no CDN, no storage APIs.

Pages:
1. What DSPy is
2. The setup
3. How the optimiser works
4. The optimiser at work
